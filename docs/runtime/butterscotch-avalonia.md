# Avalonia 与 Android 内嵌运行

Avalonia 前端复用了同一套 `UndertaleModRunner`，但“游戏画面放在哪里”取决于平台：

| 平台 | 游戏画面 | 调试控制 |
|:--|:--|:--|
| Windows / Linux / macOS（Avalonia 桌面） | 引擎自建独立窗口 | 当前版本没有可用的独立调试窗口；交互式调试请使用 WPF 版 |
| Android | 应用内的 **Butterscotch** 标签页，原生 SurfaceView 直接渲染 | 游戏标签页内的调试条 |

> 桌面 Avalonia 与 WPF 共用运行/调试菜单和快捷键，但 WPF 的断点、变量、实例、调用栈、输出等独立窗口在 Avalonia 端**尚未接入**。Avalonia 已移植这些窗口的代码，但当前版本没有打开它们的入口。请以实际界面为准。

## 桌面端快速开始

1. 打开数据文件；
2. 按 **F6** 运行，或 **Shift+F6** 调试；
3. 按提示保存数据文件；
4. 游戏在独立窗口中启动。关闭该窗口即结束会话。

桌面端仍支持：

- **反汇编断点**：在代码条目的“反汇编”页左侧边栏点击设置；
- **停止行高亮**：命中后反汇编视图会标出停止位置；
- **热重载**：底层服务支持，但桌面端当前没有触发入口；Android 游戏标签页的调试条提供按钮。

如果你需要完整的 WPF 调试面板，请在 Windows 上使用 WPF 版 `UndertaleModTool.exe`。

## Android 快速开始

### 1. 安装与准备

Android 版需要：

- Android 9（API 28）或更高；
- 与设备架构匹配的 APK（arm64 或 x64）；
- 首次运行前，按[Android 安装说明](docs/platforms.md?id=android)完成存储授权（Android 10 尤其需要）。

### 2. 打开 Butterscotch 菜单

Android 上“显示 Butterscotch 调试选项”默认是**关闭**的：

1. 打开 **设置**；
2. 找到 **Butterscotch** 区域；
3. 勾选 **显示 Butterscotch 调试选项**；
4. 返回主界面。

### 3. 启动游戏

1. 打开数据文件；
2. `文件 → 使用 Butterscotch 运行`（F6）或 `使用 Butterscotch 调试`（Shift+F6）；
3. 选择是否保存；
4. 应用会打开一个 **Butterscotch** 标签页，游戏画面直接显示在标签页内。

如果提示“内置 Butterscotch 调试器需要…”，说明 APK 中没有对应 ABI 的 `libbsdbg.so`。请换用 arm64/x64 的正确安装包。

### 4. 调试条

调试会话启动后，游戏标签页会显示一条半透明调试条：

- 竖屏：底部横条；
- 横屏：左侧竖条。

按钮：

| 图标/按钮 | 作用 |
|:--|:--|
| 暂停 / 继续 | 在运行与暂停之间切换 |
| 逐语句 | 执行下一条 GML 指令 |
| 逐过程 | 执行到当前帧的下一条指令或返回 |
| 跳出 | 运行到当前调用帧返回 |
| 下一帧 | 推进一整帧后暂停 |
| 热重载 | 下发当前代码条目的修改 |
| 停止 | 结束会话 |
| 全屏 | 隐藏系统栏，仅单窗口平台显示 |

右侧文字显示 `Paused · frame N` 或 `Running · frame N`。

关闭游戏标签页会**直接停止会话**，因为原生 Surface 随标签页销毁。

### 5. 触摸与虚拟按键

Android 上没有物理键盘，应用提供三层输入：

| 输入方式 | 默认 | 行为 |
|:--|:--|:--|
| 触摸作为鼠标左键 | 开 | 手指按下 = 鼠标左键按下并移动指针；抬起 = 松开 |
| 虚拟手柄 | Android 上开 | 左下方向键 + 右下 A/B，按下/抬起注入 gamepad 按钮 |
| 虚拟键盘 | 关 | 右上角 Z / X / C / Enter / Esc，注入对应 GML 虚拟键码 |

在 **设置 → Butterscotch** 中可以分别开关：

- **虚拟手柄**；
- **虚拟键位**；
- **触摸作为鼠标左键**。

按键映射：

| 控件 | GameMaker 常量/键码 |
|:--|:--|
| 方向键上/下/左/右 | gamepad 按钮 12 / 13 / 14 / 15 |
| A | gamepad 按钮 0 |
| B | gamepad 按钮 1 |
| Z / X / C | 键码 90 / 88 / 67 |
| Enter / Esc | 键码 13 / 27 |

> 这三个设置项的界面文字目前是硬编码中文，不随界面语言切换。

### 6. 全屏

调试条上的全屏按钮会调用 Android 的沉浸模式：

- Android 11（API 30）及以上使用 `WindowInsetsController`；
- 旧版本使用 `SystemUiFlags`。

全屏是尽力而为的操作，失败不会中断游戏。

## 与 WPF 的差异

| 能力 | WPF | Avalonia 桌面 | Android |
|:--|:--:|:--:|:--:|
| 运行游戏 | ✅ | ✅ | ✅ |
| 断点（反汇编边栏） | ✅ | ✅ | ✅ |
| 停止行高亮 | ✅ | ✅ | ✅ |
| 调试面板 / 变量 / 实例 / 调用栈 / 输出窗口 | ✅ | ❌ 未接入 | ❌ |
| 游戏标签页内调试条 | — | ❌ | ✅ |
| 虚拟手柄 / 键盘 | — | 可显示（需表面） | ✅ |
| 全屏 | — | ❌ | ✅ |

## 故障排查

| 现象 | 处理 |
|:--|:--|
| Android 上菜单里没有 Butterscotch | 在设置中打开“显示 Butterscotch 调试选项” |
| 提示内置运行器不可用 | APK 缺少对应 ABI 的 `libbsdbg.so`，换 arm64/x64 包 |
| 游戏标签页 5 秒内未就绪 | 原生 Surface 创建失败；关闭标签页重试，或重启应用 |
| 触摸没有反应 | 检查“触摸作为鼠标左键”是否被关闭；某些游戏只读取键盘/手柄 |
| 虚拟手柄挡住画面 | 在设置中关闭虚拟手柄，或改用外接手柄 |
| 桌面 Avalonia 调试无法继续 | 当前版本没有桌面调试控制条；改用 WPF 版进行交互式调试 |
