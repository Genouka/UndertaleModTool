# 纹理页迁移

把纹理页上的条目移动到另一张纹理页，或打包进一张新纹理页，从而合并贴图、清理碎片页、控制纹理页数量。

> README 称之为“纹理页迁移工具”，实际界面名称是 **“合并到其它纹理页”**。**仅 WPF 版支持。**

## 入口

1. 在左侧资源树中展开 **纹理页**（Embedded Textures）；
2. 双击打开一个纹理页；
3. 点击编辑器底部的 **转移到其它纹理页**。

## 操作步骤

### 第一步：选择要移动的条目

对话框左侧显示整张纹理页，并在每个条目上叠加可点击的矩形；右侧是条目列表。

- 点击页面上的矩形，或点击列表项，切换选中状态；
- 支持 **全选 / 取消全选 / 反选**；
- 顶部显示“已选 X / Y 项”；
- 绿色矩形表示已选中，蓝色表示未选中。

### 第二步：选择目标纹理页

- 目标下拉框默认是 **`<新建纹理页>`**；
- 也可以选择除当前页以外的任意已有纹理页；
- 选择后实时预览：
  - 目标纹理页；
  - 源纹理页移动后的剩余内容；
  - 合并结果与页面尺寸。

确认无误后点击 **确认**。

## 合并行为

- 页面最大尺寸 4096；
- 条目间距 2px；
- 页面尺寸取能容纳内容的 2 的幂；
- 优先尝试保留目标页已有条目的位置，只追加新条目；
- 放不下时会对目标页做完整重排；
- 被移动条目的 `SourceX/Y/Width/Height` 会更新，`TexturePage` 指向目标页；
- `TargetX/Y/Width/Height`、`BoundingWidth/Height` 保留原值；
- 如果目标选择“新建纹理页”，会创建 `Texture N` 并加入纹理页列表；
- 如果**移走源页全部条目**，源页会被替换成 1×1 透明图；
- 如果只移走部分条目，剩余条目会重新打包回源页。

## 适用场景

| 场景 | 做法 |
|:--|:--|
| 多个小纹理页合并成一张 | 对每个小页执行本工具，目标选同一张大页 |
| 把新导入的贴图并进现有页 | 新页 → 目标页 |
| 从大页中拆出部分内容 | 选择条目 → 新建纹理页 |
| 清理只剩少量内容的碎片页 | 把剩余条目移到其他页，源页变成 1×1 占位 |
| 纹理页数量触达引擎上限 | 合并页面，减少 `EmbeddedTextures` 数量 |

## 限制与风险

- **不能选择同一个纹理页**；
- 目标页放不下时会报“无法将所选条目打包到目标纹理页”；
- **完整重排会移动目标页上原有条目的位置**；依赖硬编码纹理坐标的 mod 可能受影响；
- 没有内置撤销；操作前请备份数据文件，或先另存一份；
- 只修改内存数据，必须保存数据文件后才生效；
- 不处理纹理组信息、预加载设置或纹理页名称；合并后请在纹理组编辑器中检查；
- 1×1 占位纹理页仍会占用一个纹理页条目，必要时手动删除或复用；
- 只支持 WPF。

## 故障排查

| 现象 | 处理 |
|:--|:--|
| 按钮不可见 | 确认打开的是“纹理页”资源，而不是纹理页条目 |
| 预览一直显示“处理中” | 页面较大时需要时间；等待完成或取消后重试 |
| 合并后游戏贴图错位 | 可能依赖了原纹理坐标；从备份恢复，改用“新建纹理页”并手动调整 |
| 目标页原有内容错位 | 发生了完整重排；考虑改选更大的目标页或新建页 |
| 保存后没有变化 | 工具只改内存；确认已保存数据文件 |
