# 导入 yymps 包

`.yymps` 是 GameMaker Studio 2 的本地资源包（Local Package），本质是一个 ZIP，里面包含项目的一个子集。本分支可以直接把包里的资源合并进当前数据文件。

> **仅 WPF 版支持。**

## 入口

`文件 → 从 YYMPs 包导入...`

当前必须已经打开一个数据文件。

## 操作步骤

1. 打开目标数据文件；
2. 选择 `文件 → 从 YYMPs 包导入...`；
3. 选择 `.yymps` 文件；
4. 设置名称冲突处理（跳过 / 覆盖 / 重命名）；
5. 决定是否自动包含依赖项；
6. 在资源列表中勾选要导入的项；
7. 点击 **导入**；
8. 查看结果摘要与警告。

界面与[从其他数据文件导入](docs/tools/import-datafile.md)相同，只是数据源从另一个 `data.win` 变成了 `.yymps` 包。

## 支持的资源类型

| 包内目录 | 资源类型 | 说明 |
|:--|:--|:--|
| `sprites/` | 精灵 | 图像帧、原点、序列信息 |
| `sounds/` | 声音 | `.wav` / `.ogg` / `.mp3` |
| `objects/` | 游戏对象 | 事件代码、父对象、碰撞、物理属性 |
| `scripts/` | 脚本 | GML 源码 |
| `fonts/` | 字体 | 字形与字体纹理 |

以下目录会被**跳过**，并在提示中列出数量：

`backgrounds`、`tilesets`、`paths`、`rooms`、`shaders`、`sequences`、`animcurves`、`notes`、`extensions`、`timelines`、`particles`。

> 也就是说，yymps 导入不是“整包导入”。房间、背景、路径、着色器等需要先转换成支持的类型，或使用其他导入方式。

## 导入细节

- **对象**先创建外壳，再导入精灵、字体、声音，最后填充对象事件；这样父对象、碰撞对象之间的引用可以解析；
- **脚本**会按目标版本处理：
  - GMS 2.3+：创建 `gml_GlobalScript_<name>` 并加入 Global Init；
  - 2.3 之前：创建 `gml_Script_<name>` 和 Scripts 条目；
- **精灵**帧按包内 PNG 导入，缺失帧会留空并警告；
- **字体**纹理不裁剪，因为字形坐标基于完整图像；
- **声音**支持 `.wav`、`.ogg`、`.mp3`；其他扩展名会警告并跳过；`.wav` 作为内嵌音频，其他作为压缩音频；
- **对象变量定义**不会导入；
- **拖拽（DnD）事件**没有 GML 源码，会被跳过并计数；
- 精灵自定义原点需要包内的 sequence 数据；缺失时原点回退到左上角。

## 依赖项

勾选“自动包含依赖项”时，导入器会沿着对象引用收集：

- 父对象；
- 碰撞对象；
- 事件中引用的对象；
- 这些对象再引用的精灵、声音、字体、脚本等。

依赖缺失会记录警告，不会阻止其余资源导入。

## 限制与注意事项

- 目标数据文件必须包含代码表（`Code`），否则脚本/对象导入会报错；
- 目标版本与包版本差异过大时，资源字段可能缺失或被忽略；
- 同名资源按冲突策略处理；
- 房间、背景、路径、着色器、序列等**不在支持范围**；
- 导入后请检查对象事件、脚本编译结果和纹理页布局；
- 保存前备份原始数据文件。

## 与“从文件导入”的区别

| 项目 | 从数据文件导入 | 从 yymps 导入 |
|:--|:--|:--|
| 数据源 | 另一个 `data.win` 等 | GameMaker 本地资源包 |
| 支持类型 | 14 类（声音、精灵、对象、房间、序列等） | 5 类（精灵、声音、对象、脚本、字体） |
| 房间/背景/路径 | 支持 | 不支持 |
| 适用场景 | 整游戏之间搬资源 | 导入 GameMaker 市场/教程资源包 |
