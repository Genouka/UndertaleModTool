# 重构、包围模板与代码片段

这三个功能**仅 WPF 版**提供，入口都在 GML 反编译页的右键菜单。

> 它们只修改当前文档的文本。除了“封装为脚本”会创建新资源外，重命名**不会**自动更新其他代码条目中的引用。重构后请自行搜索并检查相关代码。

## 重构菜单

右键 → **重构**，包含四项：

| 菜单项 | 作用 |
|:--|:--|
| 重命名... | 重命名当前符号 |
| 封装为脚本... | 把选中的代码提取成新脚本 |
| 转换为 if-else 链 | 把 `switch` 改写为 `if / else if / else` |
| 转换为 switch-case 链 | 把对同一主体的 `==` 比较改写为 `switch` |

### 重命名

把光标放在符号上（或右键该符号），选择 **重命名...**，输入新名称。默认填入原名，取消即中止。

支持的目标：

| 目标 | 行为 |
|:--|:--|
| 局部变量 | 修改 `UndertaleCodeLocals` 中的名称，并同步 `Variables` 中匹配的 local 条目 |
| 函数 | 修改函数名；GMS 2.3+ 同步同名 `Self`/`Undefined` 变量；同步同名脚本和 `gml_Script_*` / `gml_GlobalScript_*` 代码条目名 |
| 脚本 | 同步脚本名、同名函数名和代码条目名 |
| 资源 | 修改任意 `UndertaleNamedResource` 的名称（精灵、对象等） |
| 实例变量 / 全局变量 | 修改变量名；`global.` 前缀区分全局与实例 |

会被拒绝的情况：

- 内置函数、常量、内置实例变量/全局变量不可重命名；
- 新名称不是合法标识符，或是关键字；
- 与已有脚本重名；
- 找不到符号。

**作用范围**：仅当前文档文本。其他代码条目中对旧名称的引用不会自动更新。

### 封装为脚本

1. 选中一段 GML；
2. 右键 → **重构 → 封装为脚本...**；
3. 输入脚本名（默认 `scr_new_script`）。

生成规则：

- **GMS 2.3+**：创建 `gml_GlobalScript_<name>` 代码条目，内容为 `function <name>() { ... }`，并加入 Global Init 列表；
- **2.3 之前**：创建 `gml_Script_<name>`，并定义函数。

成功后，选区会被替换为 `<name>()`。如果编译失败，会回滚已创建的脚本、代码条目、局部变量、Global Init 和函数。

脚本名必须是合法标识符，且不能与已有脚本重名。

### switch 与 if 互转

**转换为 if-else 链**：

- 光标或选区必须位于可解析的 `switch` 中；
- case 标签表达式必须受支持且非空；
- case 体内如果有无法在 if-else 中表达的 `break`，转换失败。

**转换为 switch-case 链**：

- 每个分支条件必须是对**同一主体**的简单 `==` 比较；
- 否则会提示“条件比较了不同主体”或“每个条件必须是简单 '==' 比较”。

失败时会弹出标题为“重构”的错误对话框。

## 用...包围

右键 → **用...包围**，把选区（没有选区时包围当前行）放进模板：

| 模板 | 生成内容 |
|:--|:--|
| `for` | `for (var i = 0; i < 10; i++) { ... }` |
| `while` | `while (true) { ... }` |
| `repeat` | `repeat (1) { ... }` |
| `with` | `with (all) { ... }` |
| `do ... until` | `do { ... } until (true);` |
| `if` | `if (true) { ... }` |
| `{ } 代码块` | 仅添加花括号 |

行为：

- 按原缩进风格（Tab 或 4 空格）重排；
- 占位符会自动选中，直接输入即可替换；
- 无选区时，如果光标前只有缩进，会连缩进一起替换，避免双重缩进；
- 不校验被包围代码的语义。

## 代码片段

### 使用片段

右键 → **代码片段**：

- 列表显示片段名称与快捷键；
- 点击插入；
- 底部有 **管理代码片段...**。

插入时会：

- 按当前行缩进重排片段体；
- 有选区时替换选区，否则插入到光标处；
- 光标落到片段末尾。

片段也可以绑定自定义快捷键。快捷键只在编辑器获得焦点且补全窗口未打开时生效。

### 管理片段

打开 **代码片段** 窗口：

| 区域 | 说明 |
|:--|:--|
| 左侧列表 | 已有片段 |
| 新建 / 删除 | 管理列表 |
| 名称 | 必填，不区分大小写唯一 |
| 快捷键 | 直接按键捕获，如 `Ctrl+Alt+S`；Backspace 清除 |
| 片段代码（GML） | 片段正文 |
| 保存 / 关闭 | 保存后立即写入设置 |

快捷键规则：

- 必须包含 `Ctrl` 或 `Alt`，或使用 `F1`–`F24`；
- 不能与内置快捷键冲突，例如：
  - `Ctrl+N/O/S/Q/C/P/W`
  - `Ctrl+Shift+W/T/F`
  - `Ctrl+Tab`
  - `F5` / `Alt+F5` / `Shift+F5`
  - `Ctrl+K/F/H/T`
  - `F12` / `Shift+F12`
  - `Ctrl+Z/Y/Shift+Z/A/X/V`

存储位置：`settings.json` 的 `CodeSnippets` 数组，每项包含 `Name`、`Shortcut`、`Body`。

### 限制

- 仅在 GML 反编译页、非只读时可用；
- 片段不会自动编译，插入后仍需 `Ctrl+K`；
- Avalonia 版没有重构、包围和代码片段功能。

## 相关快捷键

| 快捷键 | 作用 |
|:--|:--|
| `Ctrl+K` | 编译当前代码 |
| `F12` | 转到定义 |
| `Shift+F12` | 查找所有引用 |
| `Ctrl+T` | 查找符号 |
| `Ctrl+F` / `Ctrl+H` | 查找 / 替换 |
| `Ctrl+Shift+T` | 恢复关闭的标签页 |
