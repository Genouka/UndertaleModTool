# 搜索替换与编辑选项

## 搜索与替换

### WPF

入口：

- `编辑 → 查找`，**Ctrl+F**；
- `编辑 → 替换`，**Ctrl+H**。

搜索面板浮在代码编辑器右上角，只作用于**当前编辑器文档**（反编译页和反汇编页各有一个面板），不是全工程搜索。

| 选项 | 说明 |
|:--|:--|
| `Aa` | 区分大小写 |
| `W` | 全字匹配（在模式两侧加 `\b`） |
| `.*` | 使用正则表达式 |
| 上一个 / 下一个 | 在命中之间移动 |
| 替换 | 替换当前命中 |
| 全部替换 | 替换当前文档中的全部命中 |

行为：

- 输入即搜索，所有命中以灰色高亮；
- 自动选中光标之后的第一个命中；
- `Enter` 下一个，`Shift+Enter` 上一个，`Esc` 关闭；
- 替换框按 `Enter` 替换当前命中；
- 面板关闭后移除高亮层。

注意：

- 正则非法时会静默忽略，不弹错误；
- 同时开启“全字匹配”和“正则”时，整个正则会被包进 `\b`；
- 替换和全部替换不校验 GML 语法，改完仍需编译（`Ctrl+K`）。

![搜索替换面板](assets/img/search-panel.png)

![搜索选项](assets/img/search-options.png)

### Avalonia

在代码编辑器内按 **Ctrl+F** / **Ctrl+H**，使用 AvaloniaEdit 内置的搜索面板。它提供匹配大小写、正则和全字匹配能力，并支持替换/全部替换；具体按钮布局以当前版本为准。

同样只作用于当前文档，不是全工程搜索。

## 自动换行与空白字符

### 用法

代码编辑器顶部有两个复选框：

- **自动换行**；
- **显示空白字符**。

WPF 还可以从 `编辑` 菜单切换这两项。Avalonia 没有编辑菜单，只保留编辑器顶部复选框。

| 选项 | 默认值 | 作用 |
|:--|:--:|:--|
| 自动换行 | 开 | 同时作用于反编译页和反汇编页 |
| 显示空白字符 | 关 | 显示空格和 Tab |

> README 曾提到“可以从设置窗口配置默认值”，但当前 WPF/Avalonia 的设置窗口中**没有**这两个控件。实际行为是：在编辑器里切换后会写回 `settings.json`，作为后续打开编辑器的默认值。

![自动换行与空白字符](assets/img/editor-wrap.png)

## 最近打开的文件（仅 WPF）

入口：`文件 → 最近打开`。

- 最多保留 **10** 条；
- 新打开的文件插到最前，重复项会先去重；
- 子菜单每次展开时动态重建；
- 末尾有 **清除最近打开记录**；
- 没有记录时显示禁用的“无最近打开的文件”。

点击一个不存在的文件时，会弹出警告并**立即从列表中移除**。注意：只检查文件是否存在，不校验是否可读或格式是否有效。

记录保存在 `settings.json` 的 `RecentFiles` 数组中。Avalonia 当前没有最近文件菜单。

![最近打开文件](assets/img/recent-files.png)

## 代码编辑器主题（WPF）

设置 → **代码编辑器主题**：

| 选项 | 说明 |
|:--|:--|
| 跟随程序主题 | 默认 |
| 亮色 | 强制亮色 |
| 暗色 | 强制暗色 |
| 与程序主题相反 | 程序亮则编辑器暗，反之亦然 |

修改后立即应用到所有已打开窗口，包括分离出去的标签窗口。受影响的内容包括：

- 编辑器背景；
- GML / VMASM 语法高亮；
- 标识符着色（函数、全局、常量、实例、局部各有亮暗两套颜色）；
- 补全项图标与文字；
- 悬浮面板；
- 诊断波浪线和行背景。

Avalonia 没有独立的代码编辑器主题设置，编辑器跟随应用主题（系统默认/亮/暗）。

## 增强的右键菜单

### WPF

在 GML 反编译页右键，菜单会按当前光标位置动态生成：

1. **剪切 / 复制 / 粘贴**（可在设置中关闭）；
2. 当前位置的“记号项”；
3. **重构** 子菜单；
4. **用...包围** 子菜单；
5. **代码片段** 子菜单 + **管理代码片段...**。

数字字面量的记号项：

- 列出该 ID 对应的候选资源；
- 左键：把数字替换为资源名；
- `Shift+左键`：在资源树中定位；
- 中键：定位并打开；
- 颜色值（`id > 0x50000`）：左键替换为十六进制颜色；
- 内置常量：显示常量名。

标识符/函数名：

- 左键：跳转到资源或代码；
- 中键：在新标签页打开；
- 右键：**在新标签页中打开**。

![数字字面量的右键菜单](assets/img/context-menu.png)

![编辑菜单中的查找、换行、悬浮与诊断开关](assets/img/editor-menu.png)

### Avalonia

右键菜单更简单：

- 撤销 / 重做 / 全选 / 剪切 / 复制 / 粘贴；
- 数字：候选资源、颜色、常量子菜单；
- 标识符：打开 / 在新标签页中打开。

没有重构、包围和代码片段。
